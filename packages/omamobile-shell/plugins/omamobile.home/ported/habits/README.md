# Habits

Your habits, each with a box to check it off for today, the last seven days as dots and the current streak. Tap a habit to check it off or uncheck it; tap **edit** to change the list.

A built-in home-screen widget, ported from
[`simonschubert/habits`](https://github.com/SimonSchubert/omarchy-widgets/tree/main/widgets/simonschubert/habits)
by Simon Schubert, in [omarchy-widgets](https://github.com/SimonSchubert/omarchy-widgets),
the widget store of Simon Schubert's Omalauncher.

**Differences from the original:** The habits are a setting instead of the file `~/.config/omarchy-proot/habits`, and the check-ins (the last 60 days) are kept with the placement's settings. The week dots show from three columns wide.

**Capabilities:** none.
