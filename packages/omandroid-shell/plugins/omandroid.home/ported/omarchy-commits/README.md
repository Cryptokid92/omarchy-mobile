# Omarchy commits

The latest commits on omacom/omarchy, branch quattro, with their age; the newest stands out. Tap the card for the full feed (subject, author, age and short hash, with **refresh** and **github ↗**), then a commit to open it; tap the header to go back.

A built-in home-screen widget, ported from
[`simonschubert/omarchy-commits`](https://github.com/SimonSchubert/omarchy-widgets/tree/main/widgets/simonschubert/omarchy-commits)
by Simon Schubert, in [omarchy-widgets](https://github.com/SimonSchubert/omarchy-widgets),
the widget store of Simon Schubert's Omalauncher.

**Differences from the original:** the launcher's full-screen view is a mode inside the card. The repository and branch are settings (omacom/omarchy and quattro by default). Refreshed every 10 minutes, as in the original.

**Capabilities:** `network` (api.github.com, no token).
